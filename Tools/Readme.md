# Tools

This directory contains helper utilities used during the development and testing of the bootloader.

Current tools:

- **packet_generator.py** – Generates firmware update packets used for UART bootloader testing.

The `packet_generator.py` utility was developed with assistance from **OpenAI ChatGPT**.

While the overall bootloader architecture, firmware, drivers, testing methodology, and repository design were implemented by the repository author, ChatGPT was used as a development assistant for generating and refining this helper script.
